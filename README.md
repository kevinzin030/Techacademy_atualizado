# TechAcademy — versão atualizada

Repositório destinado à versão local da plataforma acadêmica TechAcademy.

## Arquitetura planejada

- **HTML** para estrutura e marcação das páginas e templates.
- **CSS** para aparência e responsividade.
- **JavaScript** para lógica, eventos e funcionalidades.
- Persistência de demonstração via `localStorage`, sem API ou banco remoto nesta versão.

## Documentação

- [`docs/LEIA-ME-ARQUITETURA.md`](docs/LEIA-ME-ARQUITETURA.md): separação de responsabilidades e templates HTML.
- [`docs/LEIA-ME-ATUALIZACAO.txt`](docs/LEIA-ME-ATUALIZACAO.txt): aulas, PDFs e quizzes.
- [`docs/LEIA-ME.txt`](docs/LEIA-ME.txt): execução e funcionalidades do protótipo.

**Status:** a documentação já está publicada. Os arquivos executáveis do site (HTML, CSS e JS) ainda precisam ser adicionados; portanto, este repositório ainda não é uma versão executável do projeto.
